# Colors

Defined as CSS custom properties in `:root` by
[`wildfire.css`](https://github.com/papaps/wildfire-insurance-mvp/blob/demo/src/styles/wildfire.css).
Teal is the primary ink/brand color, orange is the accent used for CTAs and
active states, red is reserved for destructive/error states.
