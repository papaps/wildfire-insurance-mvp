# Typography

Two typefaces, loaded as system/web-safe fallback stacks (no font files are
bundled — swap in the real webfonts when available):

- **Serif** (`--wf-serif`): `'Source Serif 4', Georgia, 'Times New Roman', serif` — page titles, welcome headers, scores
- **Sans** (`--wf-sans`): `'Space Grotesk', system-ui, -apple-system, sans-serif` — body copy, labels, buttons
